chat.z.ai is Z.ai's consumer assistant, and since August 2026 its default engine is GLM-5.3-Flash, the multimodal model that Z.ai also publishes in weight form.

## What you can do with it

The product is positioned as a general assistant rather than a plain chat window. According to Z.ai's own documentation and site copy, its jobs include:

- **Agent work.** The assistant runs multi-step tasks rather than single replies: browsing, reading files, and producing finished artifacts such as [slides and posters](https://docs.z.ai/guides/agents/slide), which are generated by a dedicated slide agent that combines retrieval, structuring, and layout design.
- **Software and documents.** Prompt-to-website and prompt-to-code workflows, plus office output: the GLM-5.3-Flash guide lists PPTX, PDF, DOCX, and XLSX deliverables among supported professional workflows.
- **Research.** Web search is a built-in tool (the API prices it at 0.01 USD per use), so answers can be grounded in fetched pages rather than memory alone.
- **Long-horizon tasks.** Z.ai describes the Flash model as carrying tasks across many steps without losing the thread, a capability that traces back to the GLM-5.2 generation's million-token context.

## The engine underneath

GLM-5.3-Flash is the first native multimodal model in the GLM-5 series: it can observe interfaces and rendering results, which Z.ai uses to close a loop across code, browsers, and GUIs. It carries 320B total parameters with 18B active in a hybrid linear-plus-sparse attention design, is MIT licensed, and costs 0.15 USD per million input tokens on the API. The fuller story lives in [the model's section](../models/glm-5-3-flash.md).

## How to start

Open [chat.z.ai](https://chat.z.ai/) directly; the free experience is the default entry point. Paid options run through [subscriptions](https://z.ai/subscribe), and heavy coding users should look at the separate [coding plan](../code/index.md) instead, which is priced per credit rather than per chat.

## Honest limits

The usual caveats apply and are worth stating plainly: features marked beta may change, availability can differ by region, and a web interface does not expose every parameter the API does (reasoning effort and context limits among them). For anything reproducible, prefer the [API](../api/index.md).
