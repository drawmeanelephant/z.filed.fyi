本手册由公开来源汇编、由开源软件生成、使用获得许可的字体排版。凭据如下：

## 软件

- **生成器**：[la-famille](https://github.com/drawmeanelephant/la-famille)，一个 Go 静态站点生成器。本站不做任何修改地运行它；主题属于站点本地文件。
- **构建**：没有 JavaScript 构建步骤、没有框架、运行期没有包管理器。生成器二进制加上仓库源文件，就是全部工具链。

## 字体

- **General Sans**（Indian Type Foundry，经 Fontshare 获取），可变字重 200-700，Fontshare 免费字体许可。随 `assets/fonts/` 附带许可原文。
- **JetBrains Mono**，可变字重，SIL Open Font License 1.1。同目录，同规则。
- 中文使用读者系统的 CJK 字体（如苹方、Noto Sans CJK SC、微软雅黑），而非下载字体——这是为控制页面体积做的刻意取舍。

## 图像

本站附带三幅抽象图像（浅色首屏、深色首屏，以及上一页的节点连线图案）。它们是为本项目生成的原创画面；站内没有任何图库照片或第三方图像。

## 来源与方法

每个内容页都列出其来源。Z.ai 与智谱的官方文档、模型卡被视作一手材料；媒体报道标注为报道；社区信息少量使用并明确标注。会变动的数字（价格、星标、市场数据）以带核对日期的快照呈现。完整方法见[关于页](../meta/about.md)。

## 独立性

本站与智谱 AI、Z.ai 无隶属关系。产品名与商标归其所有者，仅用于识别。本站不构成任何投资建议。

## 更正

语料可版本化：包括你读过的每一页在内的站点源码存放在 Git 仓库中，下方的机器可读导出可以在两次构建之间做 diff。若有事实错误，可以在源头修正。
