Every page you are reading was generated by **la-famille**, a static site generator written in Go. This subsection documents the tool honestly: what it does, how this site uses it, and what it does not do yet.

## What la-famille is

A single Go program that turns a folder of Markdown into a complete static site - HTML pages, taxonomy archives, a client-side search index, a link graph, RSS, a sitemap, stub pages for missing links, and a machine-readable corpus export for LLM tooling. It ships with a terminal UI, an incremental build cache, a content checker, and a publish-artifact validator. It is local-first by construction: no framework, no CDN, every asset self-hosted.

The design brief, in the project's own words, is a generator that "treats content as a linked, machine-readable knowledge graph" rather than a blog engine with a graph feature bolted on.

## Why this site runs on it

This guide is the generator's first full production run outside its own documentation - a deliberate test with a real destination, two languages, and a custom theme. The constraints were the point:

- **Bilingual without an i18n framework.** Two content trees, mirrored slugs, per-language layouts, and a theme-level language switcher (details in [How this site works](how-this-site-works.md)).
- **A custom theme, not a fork.** The "zai" theme lives entirely in this site's `templates/` and `assets/` directories; the generator itself was not modified. Light/dark support, the hero, and every component are theme files.
- **Machine-readable by default.** The full corpus is exported in a format designed for feeding language models, linked at the bottom of every page.

## Where to get it

The project is open source at [github.com/drawmeanelephant/la-famille](https://github.com/drawmeanelephant/la-famille), with a single-binary quickstart: download a release archive, point it at a project directory, build. The repository's `docs/` folder carries the deep guides; this subsection is the field report from using it.
